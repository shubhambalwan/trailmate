# TrailMate

An open-source AI outdoor adventure companion designed to get people away
from their screens and into the real world.

## Core idea

Plan → Download → Put the phone away → Explore → Record → Reflect

TrailMate uses open-weight AI to generate personalized outdoor adventures,
offline challenges, observation prompts, and post-adventure journals.

## Open AI

The project is designed around open-weight models, initially targeting
Qwen3-4B-Instruct-2507 with local inference.

## Philosophy

The screen should be the shortest part of the experience.

## Status

Early development.
